Granting access to individual playbooks

Each playbook is a separate folder of files, so access is controlled per playbook. To give someone a single playbook without the rest, share only that playbook's folder (or its hub file) — for example in SharePoint, set permissions on the Marketing Playbook folder alone. This top-level hub is the master index for anyone who should see everything.
